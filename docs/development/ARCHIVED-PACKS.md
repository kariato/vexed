# Archived pack expansion

The project owner explicitly requested adding every archived pack without an explicit reproduction denial. This supersedes the previous runtime exclusion policy; it does not establish or reassign copyright permissions. All 48 canonical PDB packs (2,878 entries) are now runtime data. Classic retains its exact existing layouts and new solution asset. The other 47 packs retain author credit, exact source-file hashes and historical par, with generic level labels. Their historical solutions are converted into strict-engine-verified commands. Classic II's single documented empty-origin no-op is omitted; its historical par remains unchanged. No alternate INI solutions replace the canonical release PDB variant.

The license review remains an evidence record: Classic is explicitly GPL-2.0-or-later; Classic II has an official GPL statement without a version; the other 46 packs have unresolved adaptation terms. Historical solution terms are unresolved too. Runtime metadata uses NOASSERTION where no license is established and LicenseRef-Upstream-GPL for the limited Classic II evidence, with explanatory notes. These values describe evidence, not new grants. Public PACK_NOTICES.txt preserves author credit, source hashes, scope and this decision. The code's GPL notice does not cover all historical data by implication.

The pack selector remounts the game for a new pack, isolating transient state and IndexedDB keys. Classic keeps its original /vexed/classic save key. Switching waits for the latest save; if storage fails, abandoning an unsaved attempt requires confirmation. Query links reopen the chosen pack on reload. Corrupt saves remain protected independently per pack. Progression, score totals and level counts use the chosen pack's length.

The production service worker precaches the full manifest, all packs, all solutions and notices. Offline readiness covers all 2,878 entries. Installation and updating still require successful atomic caching; player data remains in IndexedDB rather than cache storage. The corresponding application source archive includes converted runtime data and pack notices; raw PDB/INI files, themed title lists, research catalogue and Palm binaries remain outside it.

Validation covers every manifest hash and level identity, all strict solution replays, the exact no-op normalization, per-pack saves and restoration, switching failures, and offline pack switching/reload/playback. Counts describe entries, not unique puzzles. Historical phase documents describe their milestones; this record supersedes their Classic-only runtime boundary.

Verified locally: lint, TypeScript, 199 unit/reference tests (including full runtime solution validation), 4,016 historical source replays / 74,589 atomic steps, root production build, 104 gameplay/accessibility browser checks (6 intentional platform-specific skips), and 30 production PWA checks. Gameplay projects cover Chromium desktop/tablet/phone, WebKit tablet and Firefox; PWA checks cover Chromium/WebKit/Firefox. Reviewed the rendered tablet pack-selection screenshot. These are automated device profiles, not completion of the pending physical-device/manual screen-reader release gates.
